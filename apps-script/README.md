# Receptor de clientes (Apps Script)
1. Abre la planilla de Niebla > Extensiones > Apps Script, borra el contenido de `Código.gs` y pega `clientes.gs`; guarda.
2. Implementar > Nueva implementación > tipo «Aplicación web».
3. Ejecutar como: **Yo**; Quién tiene acceso: **Cualquier usuario**. Implementar y autoriza con tu cuenta.
4. Copia la URL que termina en `/exec`.
5. Pégala en `APPS_SCRIPT_URL` de `app.js`, haz commit y push. Mientras esté vacía, el sitio no envía nada.
